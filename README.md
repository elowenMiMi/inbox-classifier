# 收件箱自动整理 · Inbox Classifier

给新笔记自动建议目录与标签，**加标签前先问你**，确认后自动归类、补双链，并重建目录树。

## 功能

- **发现新笔记**：启动时 + 定时扫描（默认 10 分钟），状态栏显示待整理数量
- **判断去哪儿**：按规则文件里的关键词打分；子笔记自动跟随母题
- **新建标签先问你**：只提议「词库里没有、又在一批新笔记里反复出现」的词，勾选后才写入
- **应用即归位**：写标签 → 移动文件（内部链接自动改写）→ 文末补关联块
- **目录树重建**：命令一键按当前文件夹刷新目录树与篇数

## 安装

- 社区插件市场搜索 **收件箱自动整理**（上架后）
- 或用 BRAT 添加本仓库
- 手动：把 `main.js`、`manifest.json`、`styles.css` 放进 `<vault>/.obsidian/plugins/inbox-classifier/`

## 规则文件

默认路径 `inbox-rules.json`（可在设置里改）。示例：

```json
{
  "inbox": ["Inbox"],
  "excludeFolders": ["Templates", ".trash"],
  "defaultFolder": "90-待整理",
  "studyPattern": "单选题|选择题|判断题|简答题",
  "folders": [
    { "folder": "10-工作/11-项目A", "tag": "领域/工作/项目A", "keywords": ["项目A", "复盘"] }
  ],
  "types": [{ "tag": "类型/复盘", "keywords": ["复盘"] }],
  "projects": [{ "tag": "项目/X", "keywords": ["X"] }],
  "pinned": [{ "title": "某篇固定笔记", "folder": "10-工作" }],
  "treeLabels": { "10-工作": "工作相关" }
}
```

- `folders` 按顺序匹配，先命中先用
- `pinned` 是人工固定项（标题 → 目录），按标题长度优先
- 规则文件缺失或解析失败时**停止整理**，不会乱动你的笔记

## 设置

规则文件路径 / 实体卡片文件夹 / 目录树笔记路径 / 启动时扫描 / 扫描间隔 / 自动弹窗 / 全库扫描 / 清理「已跳过」记录

## 已知限制

- 规则是关键词匹配，不理解语义；规则文件需要自己维护
- 只处理 `.md`；重命名或移动后需重新扫描
